4 Uji otomatis

Uji validasi mengirim input yang seharusnya ditolak; tidak menulis apa pun ke GitHub. Uji alur lengkap menjalankan post → update → update_or_add → delete pada file ujiotomatis.json dan membuat sekitar 5 commit. Uji origin palsu tidak bisa dilakukan dari browser; gunakan opsi 11 di dekeku.bat.

5 Buat token JWT uji

Hanya untuk uji lokal. Jangan masukkan JWT_SECRET produksi di halaman ini, dan jangan unggah halaman ini ke situs publik. Token untuk pengguna sungguhan harus dibuat di server.
